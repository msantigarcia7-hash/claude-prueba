Notación: $y = y(x)$ es la función incógnita, $y' = \frac{\mathrm{d}y}{\mathrm{d}x}$; $M_y = \frac{\partial M}{\partial y}$, $N_x = \frac{\partial N}{\partial x}$; $C$ y $K$ son constantes arbitrarias. Todos los ejemplos están comprobados sustituyendo la solución en la ecuación.

1. Conceptos básicos

Ecuación diferencial ordinaria (EDO) de primer orden. Es una ecuación que relaciona $x$, una función desconocida $y(x)$ y su primera derivada $y'$: $F(x,y,y') = 0$. Se puede escribir de dos formas equivalentes: $$\text{forma normal: } y' = f(x,y), \qquad\qquad \text{forma diferencial: } M(x,y)\dd x + N(x,y)\dd y = 0 .$$ Se pasa de una a otra con $y' = \frac{\mathrm{d}y}{\mathrm{d}x} = -\frac{M}{N}$.
ConceptoSignificado
Solución generalfamilia de soluciones con una constante arbitraria $C$: $y = \varphi(x,C)$ o, en forma implícita, $\Phi(x,y) = C$
Solución particularla que se obtiene dando un valor concreto a $C$
Solución singularsolución que no se obtiene de la general para ningún valor de $C$ (aparece al dividir por una expresión que puede anularse)
Problema de valor inicial (PVI)$y' = f(x,y)$ con la condición $y(x_0) = y_0$; la condición determina $C$
Teorema de existencia y unicidad (Picard). Si $f(x,y)$ y $\frac{\partial f}{\partial y}$ son continuas en un rectángulo que contiene al punto $(x_0,y_0)$, entonces el problema $y' = f(x,y)$, $y(x_0) = y_0$ tiene una única solución definida en un intervalo alrededor de $x_0$. Si solo $f$ es continua, hay solución pero puede no ser única.

2. Cómo reconocer el tipo de ecuación

Antes de resolver, clasifica. Comprueba en este orden (de lo más sencillo a lo más laborioso):

OrdenPreguntaSi la respuesta es sí
1¿Se puede escribir $y' = g(x)\,h(y)$?Variables separables (§3)
2¿Es $y' = f(ax+by+c)$?Cambio $z = ax+by+c$ (§4)
3¿Es lineal en $y$ e $y'$: $y' + P(x)\,y = Q(x)$?Lineal (§9)
4¿Es $y' + P(x)\,y = Q(x)\,y^n$?Bernoulli (§10)
5¿Es $f(\lambda x,\lambda y) = f(x,y)$?Homogénea (§5)
6¿Es $y' = f\!\left(\frac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2}\right)$?Reducible a homogénea (§6)
7En forma $M\dd x + N\dd y = 0$, ¿es $M_y = N_x$?Exacta (§7)
8¿No es exacta, pero $\frac{M_y-N_x}{N}$ solo depende de $x$ (o $\frac{N_x-M_y}{M}$ solo de $y$)?Factor integrante (§8)
9¿Es $y' = P + Q\,y + R\,y^2$ y conozco una solución $y_1$?Riccati (§11)
10¿No se puede despejar $y'$, y es $y = x\,\varphi(y') + \psi(y')$?Clairaut o Lagrange (§12)

Una misma ecuación puede pertenecer a varios tipos (por ejemplo, $y' = xy$ es separable y también lineal). Elige el método más corto.

3. Variables separables

FormaMétodoSolución
$y' = g(x)\,h(y)$   o   $M_1(x)N_1(y)\dd x + M_2(x)N_2(y)\dd y = 0$separar: todo lo de $y$ con $\mathrm{d}y$, todo lo de $x$ con $\mathrm{d}x$$\displaystyle\int\frac{\mathrm{d}y}{h(y)} = \int g(x)\dd x + C$

Pasos. (1) Escribir $y' = \frac{\mathrm{d}y}{\mathrm{d}x}$. (2) Pasar $h(y)$ dividiendo y $\mathrm{d}x$ multiplicando. (3) Integrar cada lado (una sola constante). (4) Despejar $y$ si se puede.

Cuidado con las soluciones perdidas. Al dividir por $h(y)$ se supone $h(y)\neq 0$. Los valores $y = y_0$ con $h(y_0) = 0$ son soluciones constantes que hay que añadir si no están incluidas en la general.

Caso particular, ecuación autónoma $y' = h(y)$: es separable; sus soluciones constantes ($h(y_0) = 0$) se llaman puntos de equilibrio.

Ejemplo. $y' = xy$,   $y(0) = 2$ $$\frac{\mathrm{d}y}{y} = x\dd x \;\Rightarrow\; \ln|y| = \frac{x^2}{2} + C \;\Rightarrow\; y = K e^{x^2/2} \quad (K = \pm e^C;\ K = 0 \text{ recupera la solución } y = 0).$$

Con $y(0) = 2$: $K = 2$, luego $y = 2e^{x^2/2}$.

4. Reducibles a separables: $y' = f(ax+by+c)$

FormaCambioEcuación que resulta
$y' = f(ax+by+c)$$z = ax+by+c$,   $z' = a + b\,y'$$z' = a + b\,f(z)$   (separable): $\displaystyle\int\frac{\mathrm{d}z}{a+b\,f(z)} = x + C$
Ejemplo. $y' = (x+y)^2$

$z = x+y$, $z' = 1 + y' = 1 + z^2$. Separando: $\int\frac{\mathrm{d}z}{1+z^2} = \int\mathrm{d}x \Rightarrow \arctg z = x + C \Rightarrow z = \tg(x+C)$.

$$y = \tg(x+C) - x .$$

5. Ecuaciones homogéneas

Función homogénea. $g(x,y)$ es homogénea de grado $k$ si $g(\lambda x,\lambda y) = \lambda^k g(x,y)$ para todo $\lambda>0$. La EDO $y' = f(x,y)$ es homogénea si $f$ es homogénea de grado $0$, es decir, $f(\lambda x,\lambda y) = f(x,y)$; equivalentemente, en $M\dd x + N\dd y = 0$, si $M$ y $N$ son homogéneas del mismo grado. Entonces $f$ solo depende del cociente $\frac{y}{x}$.
FormaCambioEcuación que resulta
$y' = f\!\left(\dfrac{y}{x}\right)$$y = v\,x$,   $y' = v + x\,v'$$x\,v' = f(v) - v$   (separable): $\displaystyle\int\frac{\mathrm{d}v}{f(v)-v} = \ln|x| + C$

Al terminar se deshace el cambio con $v = \frac{y}{x}$. Las raíces de $f(v) = v$ dan soluciones rectas $y = v_0\,x$. (Si $\mathrm{d}x$ resulta más complicado, también vale el cambio $x = u\,y$.)

Ejemplo. $y' = \dfrac{x^2+y^2}{xy}$

Numerador y denominador son homogéneos de grado $2$. Con $y = vx$: $v + xv' = \frac{1+v^2}{v} = \frac{1}{v} + v$, luego $xv' = \frac{1}{v}$.

$$v\dd v = \frac{\mathrm{d}x}{x} \;\Rightarrow\; \frac{v^2}{2} = \ln|x| + C \;\Rightarrow\; y^2 = 2x^2\ln|x| + Cx^2 .$$

6. Reducibles a homogéneas

Forma: $\displaystyle y' = f\!\left(\frac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2}\right)$. Se mira si las rectas $a_1x+b_1y+c_1 = 0$ y $a_2x+b_2y+c_2 = 0$ se cortan o son paralelas:

CasoCondiciónCambioResulta
Rectas que se cortan en $(x_0,y_0)$$\begin{vmatrix}a_1&b_1\\a_2&b_2\end{vmatrix}\neq 0$$X = x - x_0$,   $Y = y - y_0$$Y' = f\!\left(\dfrac{a_1X+b_1Y}{a_2X+b_2Y}\right)$, homogénea
Rectas paralelas$\begin{vmatrix}a_1&b_1\\a_2&b_2\end{vmatrix} = 0$$z = a_1x + b_1y$separable en $z$
$c_1 = c_2 = 0$—ningunoya es homogénea
Ejemplo 1 (se cortan). $y' = \dfrac{x+y-3}{x-y-1}$

$x+y = 3$, $x-y = 1$ $\Rightarrow$ $(x_0,y_0) = (2,1)$. Con $X = x-2$, $Y = y-1$: $Y' = \frac{X+Y}{X-Y}$. Con $Y = vX$:

$$v + Xv' = \frac{1+v}{1-v} \;\Rightarrow\; Xv' = \frac{1+v^2}{1-v} \;\Rightarrow\; \int\frac{1-v}{1+v^2}\dd v = \int\frac{\mathrm{d}X}{X} \;\Rightarrow\; \arctg v - \frac{1}{2}\ln(1+v^2) = \ln|X| + C .$$

Deshaciendo los cambios ($v = \frac{y-1}{x-2}$):

$$\arctg\frac{y-1}{x-2} = \ln\sqrt{(x-2)^2+(y-1)^2} + C .$$
Ejemplo 2 (paralelas). $y' = \dfrac{x+y+1}{2x+2y-1}$

$\begin{vmatrix}1&1\\2&2\end{vmatrix} = 0$. Con $z = x+y$: $z' = 1 + \frac{z+1}{2z-1} = \frac{3z}{2z-1}$, separable:

$$\int\frac{2z-1}{3z}\dd z = \int\mathrm{d}x \;\Rightarrow\; \frac{2z}{3} - \frac{1}{3}\ln|z| = x + C \;\Rightarrow\; 2y - x - \ln|x+y| = C .$$

7. Ecuaciones exactas

Ecuación exacta. $M(x,y)\dd x + N(x,y)\dd y = 0$ es exacta si existe una función $F(x,y)$ (función potencial) con $F_x = M$ y $F_y = N$; es decir, si el primer miembro es la diferencial total $\mathrm{d}F$. Entonces la solución es $F(x,y) = C$. En un dominio sin agujeros (por ejemplo un rectángulo), es exacta si y solo si $$\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x} .$$

Cálculo de $F$.

  1. Integrar $M$ respecto de $x$ (con $y$ constante): $F(x,y) = \int M\dd x + \varphi(y)$.
  2. Derivar respecto de $y$ e igualar a $N$: $\frac{\partial}{\partial y}\int M\dd x + \varphi'(y) = N$. Despejar $\varphi'(y)$ (debe quedar solo función de $y$) e integrar.
  3. Solución: $F(x,y) = C$.

(También se puede empezar integrando $N$ respecto de $y$ y añadir $\psi(x)$.)

Ejemplo. $(2xy+3)\dd x + (x^2-1)\dd y = 0$

$M_y = 2x = N_x$: exacta. $F = \int(2xy+3)\dd x = x^2y + 3x + \varphi(y)$. Derivando: $F_y = x^2 + \varphi'(y) = x^2 - 1 \Rightarrow \varphi'(y) = -1 \Rightarrow \varphi(y) = -y$.

$$x^2y + 3x - y = C .$$

8. Factor integrante

Si $M\dd x + N\dd y = 0$ no es exacta, se busca una función $\mu$ tal que $\mu M\dd x + \mu N\dd y = 0$ sí lo sea, es decir, $(\mu M)_y = (\mu N)_x$. Después se resuelve como exacta. En general esta condición es una EDP, pero hay casos en que $\mu$ depende de una sola variable:

FactorCondición (debe depender solo de esa variable)Factor integrante
$\mu(x)$$\dfrac{M_y - N_x}{N} = h(x)$$\mu(x) = e^{\int h(x)\dd x}$
$\mu(y)$$\dfrac{N_x - M_y}{M} = h(y)$$\mu(y) = e^{\int h(y)\dd y}$
$\mu(z)$, $z = z(x,y)$$\dfrac{M_y - N_x}{N z_x - M z_y} = h(z)$$\mu(z) = e^{\int h(z)\dd z}$
$\mu(x+y)$$\dfrac{M_y - N_x}{N - M} = h(x+y)$$e^{\int h(z)\dd z}$,   $z = x+y$
$\mu(xy)$$\dfrac{M_y - N_x}{yN - xM} = h(xy)$$e^{\int h(z)\dd z}$,   $z = xy$
$\mu(x^2+y^2)$$\dfrac{M_y - N_x}{2xN - 2yM} = h(x^2+y^2)$$e^{\int h(z)\dd z}$,   $z = x^2+y^2$

Todas salen de la fila general: imponiendo $(\mu M)_y = (\mu N)_x$ con $\mu = \mu(z)$ se obtiene $\frac{\mu'}{\mu} = \frac{M_y-N_x}{Nz_x - Mz_y}$. Al multiplicar por $\mu$ pueden ganarse o perderse soluciones donde $\mu = 0$ o no está definido.

Ejemplo 1 ($\mu(x)$). $(x^2+y^2+x)\dd x + xy\dd y = 0$

$M_y = 2y$, $N_x = y$: no es exacta. $\frac{M_y-N_x}{N} = \frac{y}{xy} = \frac{1}{x}$, solo de $x$: $\mu = e^{\int\frac{\mathrm{d}x}{x}} = x$.

$(x^3+xy^2+x^2)\dd x + x^2y\dd y = 0$ ya es exacta ($M_y = 2xy = N_x$). $F = \frac{x^4}{4} + \frac{x^2y^2}{2} + \frac{x^3}{3} + \varphi(y)$, y $F_y = x^2y$ da $\varphi' = 0$:

$$\frac{x^4}{4} + \frac{x^2y^2}{2} + \frac{x^3}{3} = C .$$
Ejemplo 2 ($\mu(y)$). $y\dd x + (2x - y\,e^y)\dd y = 0$

$M_y = 1$, $N_x = 2$. $\frac{N_x-M_y}{M} = \frac{1}{y}$, solo de $y$: $\mu = e^{\int\frac{\mathrm{d}y}{y}} = y$.

$y^2\dd x + (2xy - y^2e^y)\dd y = 0$ es exacta ($M_y = 2y = N_x$). $F = xy^2 + \varphi(y)$; $F_y = 2xy + \varphi'(y) = 2xy - y^2e^y \Rightarrow \varphi = -\int y^2e^y\dd y = -(y^2-2y+2)e^y$ (por partes dos veces):

$$xy^2 - (y^2-2y+2)\,e^y = C .$$

9. Ecuaciones lineales

Ecuación lineal de primer orden. $y' + P(x)\,y = Q(x)$: $y$ e $y'$ aparecen con exponente $1$, sin multiplicarse entre sí ni dentro de otras funciones. Si $Q = 0$ es homogénea (incompleta); si $Q\neq 0$, completa. La solución general es siempre $y = y_h + y_p$: la general de la homogénea más una particular de la completa.

Método 1: factor integrante

Se multiplica por $\mu(x) = e^{\int P(x)\dd x}$. El primer miembro se convierte en la derivada de un producto, $(\mu\,y)' = \mu\,Q$, y se integra:

$$y = e^{-\int P(x)\dd x}\left[\int Q(x)\,e^{\int P(x)\dd x}\dd x + C\right]$$

Método 2: variación de las constantes (Lagrange)

  1. Resolver la homogénea $y' + P\,y = 0$ (separable): $y_h = C\,e^{-\int P\dd x}$.
  2. Suponer $C = C(x)$: $y = C(x)\,e^{-\int P\dd x}$. Al sustituir en la completa se cancelan los términos con $C(x)$ y queda $C'(x) = Q(x)\,e^{\int P\dd x}$.
  3. Integrar $C'(x)$ (con su constante) y sustituir. Se llega a la misma fórmula.

Si la ecuación es lineal en $x$ como función de $y$, $\frac{\mathrm{d}x}{\mathrm{d}y} + P(y)\,x = Q(y)$, se aplica lo mismo intercambiando los papeles de $x$ e $y$.

Ejemplo 1. $y' + \dfrac{y}{x} = x^2$

$P = \frac{1}{x}$, $\mu = e^{\ln x} = x$. $(xy)' = x^3 \Rightarrow xy = \frac{x^4}{4} + C$:

$$y = \frac{x^3}{4} + \frac{C}{x} .$$
Ejemplo 2 (variación de constantes). $y' - 2y = e^x$

Homogénea: $y_h = Ce^{2x}$. Con $y = C(x)e^{2x}$: $C'(x)e^{2x} = e^x \Rightarrow C'(x) = e^{-x} \Rightarrow C(x) = -e^{-x} + K$.

$$y = Ke^{2x} - e^x .$$

10. Ecuación de Bernoulli

FormaCambioEcuación que resulta
$y' + P(x)\,y = Q(x)\,y^n$,   $n\neq 0, 1$$z = y^{1-n}$,   $z' = (1-n)\,y^{-n}y'$$z' + (1-n)P(x)\,z = (1-n)Q(x)$   (lineal)

Pasos. Dividir la ecuación por $y^n$: $y^{-n}y' + P\,y^{1-n} = Q$. Con $z = y^{1-n}$ el primer término es $\frac{z'}{1-n}$. Resolver la lineal en $z$ y deshacer el cambio. Si $n>0$, $y = 0$ también es solución (se pierde al dividir por $y^n$). Con $n = 0$ o $n = 1$ la ecuación ya es lineal.

Ejemplo. $y' + \dfrac{y}{x} = x\,y^2$   ($n = 2$)

$z = y^{-1}$: $z' - \frac{z}{x} = -x$. Lineal con $\mu = \frac{1}{x}$: $\left(\frac{z}{x}\right)' = -1 \Rightarrow z = -x^2 + Cx$.

$$y = \frac{1}{Cx - x^2} \qquad(\text{y además } y = 0).$$

11. Ecuación de Riccati

FormaRequisitoCambioEcuación que resulta
$y' = P(x) + Q(x)\,y + R(x)\,y^2$conocer una solución particular $y_1$$y = y_1 + \dfrac{1}{v}$$v' + \big(Q + 2R\,y_1\big)\,v = -R$   (lineal)

También se puede usar $y = y_1 + z$, que lleva a una Bernoulli con $n = 2$: $z' - (Q+2Ry_1)\,z = R\,z^2$. La solución particular suele darse en el enunciado o se busca probando funciones sencillas ($ax$, $\frac{a}{x}$, $e^{ax}$, constantes…).

Ejemplo. $y' = y^2 - \dfrac{2}{x^2}$

Probando $y_1 = \frac{a}{x}$: $-\frac{a}{x^2} = \frac{a^2-2}{x^2} \Rightarrow a^2 + a - 2 = 0 \Rightarrow a = 1$. Así $y_1 = \frac{1}{x}$; aquí $P = -\frac{2}{x^2}$, $Q = 0$, $R = 1$.

$v' + \frac{2}{x}v = -1$, lineal con $\mu = x^2$: $(x^2v)' = -x^2 \Rightarrow v = -\frac{x}{3} + \frac{C}{x^2} = \frac{3C - x^3}{3x^2}$.

$$y = \frac{1}{x} + \frac{3x^2}{K - x^3} \qquad (K = 3C).$$

12. Ecuaciones no resueltas en $y'$: Clairaut y Lagrange

Cuando no se puede despejar $y'$, se llama $p = y'$, se deriva la ecuación respecto de $x$ y se resuelve una ecuación en $p$. La solución suele quedar en forma paramétrica (con $p$ como parámetro).

EcuaciónFormaSolución generalSolución singular
Clairaut$y = x\,p + g(p)$$y = Cx + g(C)$   (rectas)$x = -g'(p)$,   $y = -p\,g'(p) + g(p)$   (envolvente)
Lagrange$y = x\,\varphi(p) + \psi(p)$,   $\varphi(p)\neq p$resolver la lineal $\dfrac{\mathrm{d}x}{\mathrm{d}p} + \dfrac{\varphi'(p)}{\varphi(p)-p}\,x = \dfrac{\psi'(p)}{p-\varphi(p)}$;   luego $y = x\,\varphi(p) + \psi(p)$rectas $y = x\,\varphi(p_0) + \psi(p_0)$ con $\varphi(p_0) = p_0$

Origen. Derivando $y = x\varphi(p) + \psi(p)$ respecto de $x$: $p = \varphi(p) + \big(x\varphi'(p) + \psi'(p)\big)\frac{\mathrm{d}p}{\mathrm{d}x}$. En Clairaut ($\varphi(p) = p$) queda $\big(x + g'(p)\big)\frac{\mathrm{d}p}{\mathrm{d}x} = 0$: o bien $p = C$ (solución general) o bien $x = -g'(p)$ (singular). En Lagrange se toma $x$ como función de $p$ y resulta la ecuación lineal de la tabla.

Ejemplo 1 (Clairaut). $y = xy' + (y')^2$

$g(p) = p^2$. General: $y = Cx + C^2$. Singular: $x = -2p$, $y = -2p^2 + p^2 = -p^2$; eliminando $p$, $y = -\frac{x^2}{4}$ (la parábola envolvente de las rectas).

Ejemplo 2 (Lagrange). $y = 2xy' - (y')^2$

$\varphi(p) = 2p$, $\psi(p) = -p^2$. La lineal es $\frac{\mathrm{d}x}{\mathrm{d}p} + \frac{2}{p}x = 2$; con $\mu = p^2$: $(p^2x)' = 2p^2 \Rightarrow x = \frac{2p}{3} + \frac{C}{p^2}$. Entonces $y = 2xp - p^2 = \frac{p^2}{3} + \frac{2C}{p}$.

$$x = \frac{2p}{3} + \frac{C}{p^2}, \qquad y = \frac{p^2}{3} + \frac{2C}{p} .$$

Además, $\varphi(p_0) = p_0 \Rightarrow p_0 = 0$ da la solución $y = 0$.

Ejemplo (trayectorias ortogonales). Familia de parábolas $y = Cx^2$

1. EDO de la familia: derivando, $y' = 2Cx$, y eliminando $C = \frac{y}{x^2}$: $y' = \frac{2y}{x}$.

2. Ortogonales: $y' = -\frac{x}{2y}$, separable: $2y\dd y = -x\dd x \Rightarrow y^2 = -\frac{x^2}{2} + C$, es decir, la familia de elipses $x^2 + 2y^2 = K$.
