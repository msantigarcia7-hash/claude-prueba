6.4 Integrales racionales

Son integrales de la forma $\displaystyle\int\frac{P(x)}{Q(x)}\dd x$ con $P$ y $Q$ polinomios. Se resuelven siempre siguiendo los mismos pasos: dividir (si hace falta), factorizar el denominador, descomponer en fracciones simples e integrar cada fracción.

Fracción propia. $\frac{P(x)}{Q(x)}$ es propia si $\operatorname{grado}P < \operatorname{grado}Q$. La descomposición en fracciones simples solo se puede aplicar a fracciones propias.

Paso 1. Si $\operatorname{grado}P \geq \operatorname{grado}Q$, se divide

Al dividir $P$ entre $Q$ se obtienen un cociente $C(x)$ y un resto $R(x)$ con $\operatorname{grado}R < \operatorname{grado}Q$, de modo que $P = Q\cdot C + R$. Dividiendo entre $Q$:

$$\int\frac{P(x)}{Q(x)}\dd x = \int C(x)\dd x + \int\frac{R(x)}{Q(x)}\dd x .$$

La primera integral es un polinomio (inmediata) y la segunda ya es racional propia.

Paso 2. Se factoriza el denominador

Se calculan las raíces de $Q$ (fórmula de segundo grado, Ruffini, sacar factor común…). Todo polinomio con coeficientes reales se puede escribir como producto de factores de dos tipos: lineales $(x-a)$, uno por cada raíz real, y cuadráticos irreducibles $(x^2+px+q)$ con $p^2-4q<0$, uno por cada pareja de raíces complejas conjugadas. Cada factor puede aparecer elevado a una potencia (su multiplicidad).

Paso 3. Se descompone en fracciones simples

Cada factor del denominador aporta unas fracciones concretas:

Cálculo de los coeficientes. Se iguala la fracción a la suma de fracciones simples, se multiplica todo por $Q(x)$ y queda una igualdad entre polinomios que debe cumplirse para todo $x$. Hay dos técnicas, que se pueden combinar:

  • Dar valores a $x$: sobre todo las raíces reales, porque anulan casi todos los términos y dan un coeficiente directamente. Si faltan ecuaciones, se dan otros valores sencillos ($x=0$, $x=2$…).
  • Igualar coeficientes: dos polinomios son iguales si y solo si tienen los mismos coeficientes en cada potencia de $x$.

a) Raíces reales simples

Las raíces son reales y distintas entre sí. Las raíces simples siempre dan logaritmos.

Ejemplo. $\displaystyle\int\frac{x^3+x^2+x+2}{x^2-3x+2}\dd x$

Paso 1. $\operatorname{grado}P = 3 \geq 2 = \operatorname{grado}Q$, así que se divide: cociente $C(x) = x+4$, resto $R(x) = 11x-6$. (Comprobación: $(x^2-3x+2)(x+4) + 11x - 6 = x^3+x^2+x+2$.)

$$\int\frac{x^3+x^2+x+2}{x^2-3x+2}\dd x = \int(x+4)\dd x + \int\frac{11x-6}{x^2-3x+2}\dd x = \frac{x^2}{2} + 4x + \int\frac{11x-6}{x^2-3x+2}\dd x .$$

Paso 2. $x^2-3x+2 = 0 \Rightarrow x = 1,\ x = 2$, luego $x^2-3x+2 = (x-1)(x-2)$: dos raíces reales simples.

Paso 3.

$$\frac{11x-6}{(x-2)(x-1)} = \frac{A}{x-2} + \frac{B}{x-1} \;\Longrightarrow\; 11x-6 = A(x-1) + B(x-2).$$

Si $x=1$: $5 = -B$, luego $B = -5$.   Si $x=2$: $16 = A$.

Paso 4.

$$\int\frac{11x-6}{x^2-3x+2}\dd x = 16\int\frac{\mathrm{d}x}{x-2} - 5\int\frac{\mathrm{d}x}{x-1} = 16\ln|x-2| - 5\ln|x-1| .$$

Resultado.

$$\int\frac{x^3+x^2+x+2}{x^2-3x+2}\dd x = \frac{x^2}{2} + 4x + 16\ln|x-2| - 5\ln|x-1| + C .$$

b) Raíces reales múltiples

Si una raíz $a$ se repite $n$ veces, hay que poner $n$ fracciones, con denominadores $(x-a), (x-a)^2, \dots, (x-a)^n$. Las raíces múltiples dan potencias (además del logaritmo de la primera fracción).

Ejemplo. $\displaystyle\int\frac{x+1}{x^2-6x+9}\dd x$

Es propia. $x^2-6x+9 = (x-3)^2$: raíz real doble $x = 3$.

$$\frac{x+1}{(x-3)^2} = \frac{A}{x-3} + \frac{B}{(x-3)^2} \;\Longrightarrow\; x+1 = A(x-3) + B .$$

Si $x=3$: $B = 4$.   Si $x=0$: $1 = -3A + 4$, luego $A = 1$.

$$\int\frac{x+1}{x^2-6x+9}\dd x = \int\frac{\mathrm{d}x}{x-3} + 4\int(x-3)^{-2}\dd x = \ln|x-3| + 4\frac{(x-3)^{-1}}{-1} + C = \ln|x-3| - \frac{4}{x-3} + C .$$

c) Raíces complejas simples

El denominador tiene un factor $x^2+px+q$ sin raíces reales ($p^2-4q<0$). Pueden dar un logaritmo, una arcotangente o una suma de ambos. Hay tres casos:

c.1) Numerador constante: arcotangente

$1+x^2 = 0 \Rightarrow x = \pm\sqrt{-1}$, complejas. $\displaystyle\int\frac{\mathrm{d}x}{1+x^2} = \arctg x + C$.

c.2) Numerador proporcional a la derivada del denominador: logaritmo

$\displaystyle\int\frac{x\dd x}{1+x^2} = \frac{1}{2}\int\frac{2x\dd x}{1+x^2} = \frac{1}{2}\ln(1+x^2) + C$ (no hace falta valor absoluto: $1+x^2>0$).

c.3) Caso general: logaritmo + arcotangente

Se hace en dos pasos. 1.º Conseguir el logaritmo: se ajusta el numerador para que aparezca la derivada del denominador, y lo que sobra es una constante. 2.º Buscar la arcotangente: con la constante que sobra, se completa el cuadrado en el denominador («método de los cuadrados perfectos»).

Caso sencillo: $\displaystyle\int\frac{x+3}{1+x^2}\dd x = \frac{1}{2}\int\frac{2x}{1+x^2}\dd x + 3\int\frac{\mathrm{d}x}{1+x^2} = \frac{1}{2}\ln(1+x^2) + 3\arctg x + C$.

Ejemplo completo. $\displaystyle\int\frac{x+3}{x^2+2x+10}\dd x$

Raíces del denominador: $x = \frac{-2\pm\sqrt{4-40}}{2}$, complejas. La derivada del denominador es $2x+2$.

1.º Logaritmo. Multiplico y divido por $2$ y escribo $2x+6 = (2x+2) + 4$:

$$\int\frac{x+3}{x^2+2x+10}\dd x = \frac{1}{2}\int\frac{2x+6}{x^2+2x+10}\dd x = \frac{1}{2}\int\frac{2x+2}{x^2+2x+10}\dd x + \frac{1}{2}\int\frac{4\dd x}{x^2+2x+10}$$ $$= \frac{1}{2}\ln(x^2+2x+10) + 2\int\frac{\mathrm{d}x}{x^2+2x+10} .$$

2.º Arcotangente. Completo el cuadrado: $x^2+2x+10 = (x+1)^2 - 1 + 10 = (x+1)^2 + 9$. Saco el $9$ factor común:

$$\int\frac{\mathrm{d}x}{(x+1)^2+9} = \frac{1}{9}\int\frac{\mathrm{d}x}{1+\left(\frac{x+1}{3}\right)^2} = \frac{1}{9}\cdot 3\int\frac{\frac{1}{3}\dd x}{1+\left(\frac{x+1}{3}\right)^2} = \frac{1}{3}\arctg\frac{x+1}{3} .$$

Resultado.

$$\int\frac{x+3}{x^2+2x+10}\dd x = \frac{1}{2}\ln(x^2+2x+10) + \frac{2}{3}\arctg\frac{x+1}{3} + C .$$

Completar el cuadrado (regla general). $x^2+px+q = \left(x+\frac{p}{2}\right)^2 + \left(q-\frac{p^2}{4}\right)$, y como $p^2-4q<0$, el número $k^2 = q - \frac{p^2}{4}$ es positivo. Entonces $\int\frac{\mathrm{d}x}{(x+\frac{p}{2})^2+k^2} = \frac{1}{k}\arctg\frac{x+p/2}{k}$.

Fórmula general (para comprobar):

$$\int\frac{Mx+N}{x^2+px+q}\dd x = \frac{M}{2}\ln(x^2+px+q) + \frac{2N-Mp}{\sqrt{4q-p^2}}\arctg\frac{2x+p}{\sqrt{4q-p^2}} + C \qquad (p^2-4q<0).$$

En el ejemplo: $M=1$, $N=3$, $p=2$, $q=10$, $\sqrt{4q-p^2} = 6$, y sale $\frac{1}{2}\ln(\dots) + \frac{4}{6}\arctg\frac{2x+2}{6}$, lo mismo.

d) Raíces complejas múltiples: método de Hermite

Cuando el denominador tiene factores cuadráticos irreducibles repetidos, $(x^2+px+q)^n$ con $n\geq 2$, la descomposición ordinaria lleva a integrales del tipo $\int\frac{\mathrm{d}x}{(x^2+px+q)^n}$, que son largas. El método de Hermite evita esas integrales separando la parte racional del resultado. En los apuntes se indica que «no suelen entrar», pero conviene saber hacerlo.

Enunciado. Sea $\frac{P(x)}{Q(x)}$ propia. Se definen:

  • $D(x)$: el polinomio $Q(x)$ con cada factor elevado a una unidad menos (los factores que estaban elevados a $1$ desaparecen). Es el máximo común divisor de $Q$ y $Q'$.
  • $Q^*(x) = \dfrac{Q(x)}{D(x)}$: el producto de todos los factores distintos de $Q$, cada uno elevado a $1$.

Entonces existe un polinomio $N(x)$ con $\operatorname{grado}N < \operatorname{grado}D$ tal que

$$\int\frac{P(x)}{Q(x)}\dd x = \frac{N(x)}{D(x)} + \int\frac{R(x)}{Q^*(x)}\dd x ,$$

donde $\frac{R(x)}{Q^*(x)}$ se descompone en fracciones simples con todas las raíces simples (solo da logaritmos y arcotangentes).

Cómo se calculan los coeficientes. $N(x)$ se escribe con coeficientes indeterminados ($ax+b$, $ax^2+bx+c$…) y $\frac{R}{Q^*}$ como suma de fracciones simples con coeficientes indeterminados. Se deriva la igualdad anterior:

$$\frac{P(x)}{Q(x)} = \frac{\mathrm{d}}{\mathrm{d}x}\left[\frac{N(x)}{D(x)}\right] + \frac{R(x)}{Q^*(x)} ,$$

se multiplica todo por $Q(x)$ y se igualan coeficientes (o se dan valores a $x$).

Ejemplo 1. $\displaystyle\int\frac{\mathrm{d}x}{(x^2+1)^2}$

Factores. $Q = (x^2+1)^2$, factor complejo doble. Bajando un grado: $D = x^2+1$. Factores distintos: $Q^* = x^2+1$.

Planteamiento. $\operatorname{grado}D = 2$, así que $N = ax+b$. Y $\frac{R}{Q^*} = \frac{cx+d}{x^2+1}$:

$$\int\frac{\mathrm{d}x}{(x^2+1)^2} = \frac{ax+b}{x^2+1} + \int\frac{cx+d}{x^2+1}\dd x .$$

Derivo. $\displaystyle\left(\frac{ax+b}{x^2+1}\right)' = \frac{a(x^2+1) - (ax+b)\,2x}{(x^2+1)^2} = \frac{-ax^2 - 2bx + a}{(x^2+1)^2}$, luego

$$\frac{1}{(x^2+1)^2} = \frac{-ax^2-2bx+a}{(x^2+1)^2} + \frac{cx+d}{x^2+1} .$$

Multiplico por $(x^2+1)^2$ y ordeno:

$$1 = -ax^2 - 2bx + a + (cx+d)(x^2+1) = c\,x^3 + (d-a)\,x^2 + (c-2b)\,x + (a+d) .$$

Igualo coeficientes: $x^3$: $c = 0$;   $x^2$: $d - a = 0$;   $x$: $c - 2b = 0 \Rightarrow b = 0$;   término independiente: $a + d = 1$. Por tanto $a = d = \frac{1}{2}$, $b = c = 0$.

Resultado.

$$\int\frac{\mathrm{d}x}{(x^2+1)^2} = \frac{x}{2(x^2+1)} + \frac{1}{2}\int\frac{\mathrm{d}x}{x^2+1} = \frac{x}{2(x^2+1)} + \frac{1}{2}\arctg x + C .$$

Comprobación. Derivando: $\frac{1}{2}\cdot\frac{1-x^2}{(x^2+1)^2} + \frac{1}{2}\cdot\frac{1}{x^2+1} = \frac{1-x^2+x^2+1}{2(x^2+1)^2} = \frac{1}{(x^2+1)^2}$.

Ejemplo 2 (mezcla de raíces). $\displaystyle\int\frac{\mathrm{d}x}{(x-1)(x^2+1)^2}$

Factores. $(x-1)$ real simple y $(x^2+1)^2$ compleja doble. Bajando un grado cada factor: $(x-1)^0 = 1$ y $(x^2+1)^1$, así que $D = x^2+1$ y $Q^* = (x-1)(x^2+1)$.

Planteamiento.

$$\int\frac{\mathrm{d}x}{(x-1)(x^2+1)^2} = \frac{ax+b}{x^2+1} + \int\left(\frac{A}{x-1} + \frac{Mx+N}{x^2+1}\right)\mathrm{d}x .$$

Derivo y multiplico por $Q = (x-1)(x^2+1)^2$ (la derivada de $\frac{ax+b}{x^2+1}$ es la del ejemplo 1):

$$1 = (x-1)(-ax^2-2bx+a) + A(x^2+1)^2 + (Mx+N)(x-1)(x^2+1) .$$

Valor útil. Si $x = 1$: $1 = 4A$, luego $A = \frac{1}{4}$.

Igualo coeficientes (desarrollando los productos):

PotenciaEcuación
$x^4$$A + M = 0 \;\Rightarrow\; M = -\frac{1}{4}$
$x^3$$-a + N - M = 0$
$x^2$$a - 2b + 2A + M - N = 0$
$x^1$$a + 2b + N - M = 0$
$x^0$$-a + A - N = 1$

De $x^3$: $a = N + \frac{1}{4}$. Sustituyendo en $x^0$: $-N - \frac{1}{4} + \frac{1}{4} - N = 1$, luego $N = -\frac{1}{2}$ y $a = -\frac{1}{4}$. De $x^1$: $-\frac{1}{4} + 2b - \frac{1}{2} + \frac{1}{4} = 0$, luego $b = \frac{1}{4}$. (La ecuación de $x^2$ se cumple y sirve de comprobación.)

Integro lo que queda. $\displaystyle\int\frac{-\frac{1}{4}x - \frac{1}{2}}{x^2+1}\dd x = -\frac{1}{8}\ln(x^2+1) - \frac{1}{2}\arctg x$.

Resultado.

$$\int\frac{\mathrm{d}x}{(x-1)(x^2+1)^2} = \frac{1-x}{4(x^2+1)} + \frac{1}{4}\ln|x-1| - \frac{1}{8}\ln(x^2+1) - \frac{1}{2}\arctg x + C .$$

Hermite también vale para raíces reales múltiples. Por ejemplo, en $\int\frac{x+1}{(x-3)^2}\dd x$: $D = x-3$, $Q^* = x-3$, y se plantea $\frac{x+1}{(x-3)^2} = \left(\frac{a}{x-3}\right)' + \frac{A}{x-3} = \frac{-a}{(x-3)^2} + \frac{A}{x-3}$. Multiplicando: $x+1 = -a + A(x-3)$, de donde $A = 1$, $a = -4$, y se obtiene $\ln|x-3| - \frac{4}{x-3}$, igual que en el apartado b).

Alternativa: fórmula de reducción. Si se prefiere no usar Hermite, las integrales $I_k = \int\frac{\mathrm{d}x}{(1+x^2)^k}$ cumplen $$I_{k+1} = \frac{x}{2k\,(1+x^2)^k} + \frac{2k-1}{2k}\,I_k, \qquad I_1 = \arctg x .$$ Con $k=1$ se recupera el ejemplo 1. Un factor $(x^2+px+q)^k$ se lleva a esta forma completando el cuadrado y haciendo un cambio lineal.

e) Mezcla de los casos anteriores

Ejemplo. $\displaystyle\int\frac{x^2+1}{x^4-x^2}\dd x$

Es propia. $x^4 - x^2 = x^2(x^2-1) = x^2(x-1)(x+1)$: raíz real doble $x = 0$ y raíces reales simples $x = 1$, $x = -1$.

$$\frac{x^2+1}{x^4-x^2} = \frac{A}{x-1} + \frac{B}{x+1} + \frac{C}{x} + \frac{D}{x^2}$$ $$x^2+1 = A(x+1)x^2 + B(x-1)x^2 + C\,x(x+1)(x-1) + D(x-1)(x+1) .$$

Si $x=0$: $1 = -D$, $D = -1$.   Si $x=1$: $2 = 2A$, $A = 1$.   Si $x=-1$: $2 = -2B$, $B = -1$.   Si $x=2$: $5 = 12A + 4B + 6C + 3D$, es decir $5 = 12 - 4 + 6C - 3$, luego $C = 0$.

$$\int\frac{x^2+1}{x^4-x^2}\dd x = \int\frac{\mathrm{d}x}{x-1} - \int\frac{\mathrm{d}x}{x+1} - \int x^{-2}\dd x = \ln|x-1| - \ln|x+1| + \frac{1}{x} + C .$$
Errores típicos. (1) Descomponer sin haber dividido cuando $\operatorname{grado}P\geq\operatorname{grado}Q$. (2) Poner una sola fracción para una raíz doble. (3) Poner solo una constante $N$ (en vez de $Mx+N$) encima de un factor cuadrático. (4) Olvidar que $x^2-1$ no es irreducible: se factoriza como $(x-1)(x+1)$.

6.5 Integración por cambio de variable

Se sustituye una parte del integrando por una nueva variable $t$ para transformar la integral en otra más sencilla (normalmente inmediata o racional). Se usa en integrales irracionales (con raíces), con exponenciales que no son inmediatas, con logaritmos, trigonométricas, etc.

Teorema del cambio de variable. Si $x = g(t)$, con $g$ derivable, de derivada continua e invertible, entonces $$\int f(x)\dd x = \int f\big(g(t)\big)\,g'(t)\dd t ,$$ y al terminar se deshace el cambio con $t = g^{-1}(x)$. Dicho de forma práctica: al cambiar la variable hay que cambiar también el $\mathrm{d}x$, usando $\mathrm{d}x = g'(t)\dd t$.

Procedimiento. (1) Elegir el cambio. (2) Derivar para relacionar $\mathrm{d}x$ y $\mathrm{d}t$. (3) Sustituir todo: no puede quedar ninguna $x$. (4) Integrar en $t$. (5) Deshacer el cambio.

Las integrales inmediatas con $u$ son, en el fondo, cambios de variable hechos «de cabeza» ($t = u(x)$, $\mathrm{d}t = u'\dd x$).

Ejemplo 1 (raíces de distinto índice). $\displaystyle\int\frac{\sqrt{x}-\sqrt[3]{x}}{\sqrt[6]{x}}\dd x$

Índices $2, 3, 6$: $\operatorname{mcm}(2,3,6) = 12$. Cambio $x = t^{12}$, $\mathrm{d}x = 12t^{11}\dd t$. Así todas las raíces son exactas: $\sqrt{x} = t^6$, $\sqrt[3]{x} = t^4$, $\sqrt[6]{x} = t^2$.

$$\int\frac{t^6-t^4}{t^2}\cdot 12t^{11}\dd t = \int(t^4-t^2)\,12t^{11}\dd t = \int(12t^{15} - 12t^{13})\dd t = \frac{12t^{16}}{16} - \frac{12t^{14}}{14} + C = \frac{3t^{16}}{4} - \frac{6t^{14}}{7} + C .$$

Deshago el cambio, $t = \sqrt[12]{x}$, es decir $t^{16} = x^{16/12} = x^{4/3}$ y $t^{14} = x^{7/6}$:

$$\int\frac{\sqrt{x}-\sqrt[3]{x}}{\sqrt[6]{x}}\dd x = \frac{3}{4}\sqrt[3]{x^4} - \frac{6}{7}\sqrt[6]{x^7} + C .$$

(En este caso concreto también se podía simplificar antes: $\frac{x^{1/2}-x^{1/3}}{x^{1/6}} = x^{1/3} - x^{1/6}$, que es inmediata. El cambio es el método general.)

Ejemplo 2 (exponenciales). $\displaystyle\int\frac{\mathrm{d}x}{e^x+e^{-x}}$

Cambio $t = e^x$: $e^{-x} = \frac{1}{t}$ y $\mathrm{d}t = e^x\dd x$, luego $\mathrm{d}x = \frac{\mathrm{d}t}{t}$.

$$\int\frac{\mathrm{d}t/t}{t+\frac{1}{t}} = \int\frac{\mathrm{d}t/t}{\frac{t^2+1}{t}} = \int\frac{\mathrm{d}t}{t^2+1} = \arctg t + C = \arctg(e^x) + C .$$
Ejemplo 3 (trigonométrico, $\sqrt{a^2-x^2}$). $\displaystyle\int\sqrt{9-x^2}\dd x$

La curva $y = \sqrt{9-x^2}$ es la semicircunferencia superior de $x^2+y^2 = 9$ (radio $3$). Cambio $x = 3\sen t$, $\mathrm{d}x = 3\cos t\dd t$, con $t\in\left[-\frac{\pi}{2},\frac{\pi}{2}\right]$ para que $\cos t\geq 0$:

$$\int\sqrt{9-9\sen^2 t}\cdot 3\cos t\dd t = \int\sqrt{9\cos^2 t}\cdot 3\cos t\dd t = 9\int\cos^2 t\dd t .$$

Por la fórmula de reducción $\cos^2 t = \frac{1}{2}(1+\cos 2t)$ (ver 6.7):

$$9\int\frac{1}{2}(1+\cos 2t)\dd t = \frac{9}{2}\left[t + \frac{\sen 2t}{2}\right] + C .$$

Deshago el cambio: $t = \arcsen\frac{x}{3}$. Para simplificar $\frac{\sen 2t}{2} = \sen t\cos t$ uso $\sen t = \frac{x}{3}$ y $\cos t = \sqrt{1-\sen^2 t} = \frac{\sqrt{9-x^2}}{3}$:

$$\int\sqrt{9-x^2}\dd x = \frac{9}{2}\arcsen\frac{x}{3} + \frac{x\sqrt{9-x^2}}{2} + C .$$

En general: $\displaystyle\int\sqrt{a^2-x^2}\dd x = \frac{a^2}{2}\arcsen\frac{x}{a} + \frac{x\sqrt{a^2-x^2}}{2} + C$.

Ejemplo 4 (trigonométrico, $\sqrt{a^2+x^2}$). $\displaystyle\int\frac{\mathrm{d}x}{(x^2+4)^{3/2}}$

Cambio $x = 2\tg t$, $\mathrm{d}x = \frac{2}{\cos^2 t}\dd t$. Como $1+\tg^2 t = \frac{1}{\cos^2 t}$: $x^2+4 = \frac{4}{\cos^2 t}$ y $(x^2+4)^{3/2} = \frac{8}{\cos^3 t}$.

$$\int\frac{2/\cos^2 t}{8/\cos^3 t}\dd t = \frac{1}{4}\int\cos t\dd t = \frac{1}{4}\sen t + C .$$

Deshago el cambio: si $\tg t = \frac{x}{2}$, en un triángulo rectángulo de catetos $x$ y $2$ la hipotenusa es $\sqrt{x^2+4}$, luego $\sen t = \frac{x}{\sqrt{x^2+4}}$:

$$\int\frac{\mathrm{d}x}{(x^2+4)^{3/2}} = \frac{x}{4\sqrt{x^2+4}} + C .$$

Cambio de variable en integrales definidas

Si la integral es definida, se pueden cambiar también los límites de integración y así no hace falta deshacer el cambio:

$$\int_a^b f(x)\dd x = \int_{\alpha}^{\beta} f\big(g(t)\big)\,g'(t)\dd t, \qquad g(\alpha) = a,\ g(\beta) = b .$$
Ejemplo. $\displaystyle\int_0^3\sqrt{9-x^2}\dd x$

Con $x = 3\sen t$: si $x = 0$, $t = 0$; si $x = 3$, $t = \frac{\pi}{2}$.

$$\int_0^{\pi/2} 9\cos^2 t\dd t = \frac{9}{2}\left[t + \frac{\sen 2t}{2}\right]_0^{\pi/2} = \frac{9}{2}\cdot\frac{\pi}{2} = \frac{9\pi}{4} .$$

Comprobación geométrica: es un cuarto del círculo de radio $3$, cuya área es $\frac{\pi\cdot 3^2}{4} = \frac{9\pi}{4}$.
